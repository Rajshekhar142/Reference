A Quick Decision Maker that helps u to save minute time stamps like 10 min , 20 min or any duration in which u can't sit and focus for long run.
Key Features:
  1. Customized task
  2. Random task Selection (in Case u wanna do something productive but don't know what)
  3. Multiple section (devops and philosophy).
  4. Time Wise Segregation of Task
